# Embryo Stream Crawler

Embryo Stream Crawler is Embryo-Zero's fork of [incubator-stormcrawler](https://github.com/apache/incubator-stormcrawler) (f5cfe64, commit f5cfe64). It does continuous distributed web crawler.

- Our changes live on the `embryo` branch. The original license files (LICENSE, NOTICE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
